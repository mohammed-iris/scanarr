Folders & Renaming

Folders · read from qBittorrent
Set them in qBittorrent → Options → Downloads: Default Save Path = Completed, Use another path for incomplete torrents = Temp. Point them at local folders for testing or NAS folders later — nothing changes here.

Download types
Type is picked from the indexer's category. Movies and TV download to Incoming, then get subtitles and a clean name (Title (Year).mkv, Show S01E01.mkv). Other types go straight to their folder with the original name. Drop files into Unsorted by hand and they're renamed too.

Safety & Cleanup

Remove finished torrents
You don't seed: once a download is done (and renamed), the torrent is removed from qBittorrent. Files are kept.
Fake-file guard
Movie/TV torrents containing .exe .scr .lnk .bat… are a classic malware trick. They're removed with their files as soon as the file list is known.
Dead torrents
No progress for this many hours (0 = never check).
Keep free space · GB
Downloads that would leave less than this free in Temp or Completed are refused (you can override per download).

Schedule · HDD-friendly

Rename finished downloads
qBittorrent wakes the HDD anyway when it moves a finished download to Completed, so renaming right then is the most disk-friendly choice. Choose a time window if you prefer; finished downloads wait untouched until then.
